# scoop-bucket

[Scoop](https://scoop.sh) bucket for [baryon-mcp](https://github.com/combor/baryon-mcp).

```powershell
scoop bucket add combor https://github.com/combor/scoop-bucket
scoop install combor/baryon-mcp
```

Manifests are written by the baryon-mcp release pipeline on every tagged release, so changes made here by hand are overwritten. Report problems at https://github.com/combor/baryon-mcp/issues.
